# OpsLab

AI-Assisted System Operations Laboratory

## Goal

OpsLab is a 12-week project for learning practical system operations.

The project covers:

- Linux
- Networking
- Nginx
- API
- PostgreSQL
- Docker
- Monitoring
- AWS
- Incident Response
- AI-assisted operations

## Philosophy

The project does not aim to demonstrate that AI can write code.

Instead, it explores how an AI agent can assist with system operations while its actions and conclusions are verified by tests, health checks, logs, and human judgment.
